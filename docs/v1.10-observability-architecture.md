# Velo V1.10 Observability & Benchmarking Architecture

## 1. Executive Summary

Milestone **V1.10: Runtime Observability + Reproducible Benchmarking** introduces a low-overhead, thread-safe metrics and telemetry layer to Velo.
The goal is to quantitatively observe, measure, and benchmark the entire media-to-AI lifecycle without modifying scheduler decisions or imposing heavyweight third-party monitoring dependencies.

## 3. Metrics Categories & Specification

### 3.1 Video Ingestion & Scheduling Metrics
- `video_frames_received` (counter): Total frames pulled from WebRTC/NVDEC.
- `video_frames_scheduled` (counter): Frames accepted by `AIScheduler` for AI processing.
- `video_frames_dropped` (counter): Total frames dropped due to backpressure or stale ring eviction.
- `video_frames_dropped_backpressure` (counter): Frames dropped because scheduler buffer was full.
- `video_frames_dropped_stale` (counter): Frames evicted from temporal buffer due to age.
- `video_frames_skipped_scene` (counter): Visually unchanged frames filtered by scene detection.
- `candidate_evaluated` / `accepted` / `rejected` (counter): Candidate selection breakdown.
- `video_queue_depth` (gauge): Current number of frames in the scheduler ring buffer.
- `video_current_fps` (gauge): Instantaneous frame rate (rolling 1-second window).
- `video_average_fps` (gauge): Cumulative average frame rate from start.
- `video_frame_timestamp` (gauge): Monotonic session timestamp of the latest frame.

### 3.2 Audio Ingestion & Processing Metrics
- `audio_chunks_received` (counter): Total raw Opus-decoded audio chunks received.
- `audio_chunks_processed` (counter): Consolidated audio chunks dispatched to VAD/ASR.
- `audio_chunks_dropped` (counter): Audio chunks dropped due to buffer capacity bounds.
- `audio_queue_depth` (gauge): Number of samples/chunks currently buffered.
- `audio_buffered_duration_s` (gauge): Seconds of buffered audio.
- `audio_chunk_rate` (gauge): Audio chunks dispatched per second.

### 3.3 Inference & Model Metrics
- `inference_count` (counter): Total model inferences executed.
- `inference_errors` (counter): Failed inference invocations.
- `inference_queue_depth` (gauge): Items currently queued in the async result buffer.
- `inference_latency_ms` (summary): Rolling window summary (`mean`, `median`, `p95`, `p99`, `min`, `max`).
- `preprocessing_latency_ms` (summary): GPU tensor normalization/resize latency.
- `end_to_end_latency_ms` (summary): Ingestion-to-response latency (`t_response - t_frame_arrival`).

### 3.4 Temporal Fusion & Correlation Metrics
- `fusion_queries` (counter): Context alignment lookups requested.
- `matched_video_observations` (gauge): Average/latest visual frames in returned context.
- `matched_audio_observations` (gauge): Average/latest audio/transcript items in returned context.
- `timestamp_skew_ms` (summary): Temporal discrepancy $|T_{\text{video}} - T_{\text{audio}}|$ in matched observations.
- `fusion_lookup_latency_ms` (summary): Time to perform context window lookup under lock.

### 3.5 System & GPU Metrics
- `pipeline_state` (str): Current lifecycle state (`RUNNING`, `STOPPED`, etc.).
- `worker_errors` (counter): Total background worker thread exceptions.
- `uptime_s` (gauge): Elapsed seconds since pipeline startup.
- `gpu_memory_allocated_mb` (gauge): `torch.cuda.memory_allocated()` if CUDA available.
- `gpu_memory_reserved_mb` (gauge): `torch.cuda.memory_reserved()` if CUDA available.
- `gpu_max_memory_allocated_mb` (gauge): Peak GPU memory allocated.

## 4. Design Principles: Zero Telemetry Overhead & Bounded Memory

1. **Lock-Free / Cheap Atomics where possible**: In Python, simple arithmetic or lightweight `threading.Lock` guards metric snapshots.
2. **Bounded Rolling Windows**: Latencies and skew values are stored in fixed-size `collections.deque(maxlen=1000)` or streaming Welford/reservoir structures, strictly preventing unbounded memory growth.
3. **Safe Concurrency**: `.metrics()` or `.get_metrics()` constructs an immutable snapshot (`MetricsSnapshot` dataclass/dict), ensuring caller reads cannot block ingestion or inference threads.
4. **No Third-Party Telemetry Runtime**: Pure Python + PyTorch primitives. No mandatory Prometheus, OpenTelemetry, or external daemons.

## 5. Benchmark Suite Specification

The reproducible benchmark harness resides under `experiments/benchmarks/`:

1. **`video_ingestion_benchmark.py`**:
   - Stresses NVDEC decode / synthetic video injection at 30-120 FPS.
   - Measures frame arrival jitter, drop rates, and throughput.
2. **`audio_ingestion_benchmark.py`**:
   - Stresses Opus decode / synthetic audio chunks at 50-200 chunks/s.
   - Measures chunk latency, backpressure dropping, and VAD processing.
3. **`scheduler_benchmark.py`**:
   - Benchmarks `AIScheduler` pacing, adaptive EWMA reaction time, candidate selection overhead, and ring buffer contention.
4. **`fusion_benchmark.py`**:
   - Tests `TemporalFusion` lookups across high-frequency multi-modal streams (10,000 observations).
   - Measures lookup latency and timestamp skew calculation.
5. **`multimodal_pipeline_benchmark.py`**:
   - Measures end-to-end throughput, thread scaling, GPU memory stability, and latency distributions (p50/p95/p99) across 30-60s runs.
