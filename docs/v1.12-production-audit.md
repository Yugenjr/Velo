## 3. Resource Lifecycle & Concurrency Audit

### A. GPU Memory Lifetime (NVDEC -> Frame -> PyTorch)
- **Allocation**: Decoded frames are allocated directly in CUDA memory by NVIDIA NVDEC via PyNvVideoCodec.
- **DLPack Capsule**: `Frame` encapsulates a PyO3 DLPack capsule. Calling `frame.to_torch()` performs a zero-copy pointer wrap ($< 11\, \mu\text{s}$) incrementing DLPack refcounts.
- **Eviction & Deallocation**: The `AIScheduler` ring buffer has a strict `max_temporal_frames` bound. When frames age out of `temporal_window`, Python garbage collection decrements the reference, freeing the GPU surface back to NVDEC's internal pool. No memory leak detected under sustained load.

### B. Worker Thread Lifecycle in `AIPipeline`
The `AIPipeline` manages up to 4 dedicated background OS threads:
1. `_ingest_thread` (Video Ingestion)
2. `_audio_ingest_thread` (Audio Ingestion)
3. `_audio_process_thread` (VAD + ASR processing)
4. `_inference_thread` (Multimodal model execution)

- **Shutdown Handshake**: Calling `pipeline.stop()` or encountering a worker exception sets `_stop_event`, closes underlying streams and schedulers (waking threads waiting on condition variables), and joins all 4 threads with a 5.0-second timeout.
- **Verified**: 15 consecutive start/stop cycles showed zero lingering OS threads or leaked file descriptors.

## 4. Failure Resilience & Fault Injection Audit

Verified via `tests/test_failure_injection.py`:
- **Malformed RTP Payloads**: Corrupt and truncated packets pushed to `RtpReceiver` do not crash the native C++/Rust extension.
- **VAD / ASR Faults**: Exceptions during audio processing trigger `_fail()`, gracefully transitioning the pipeline to `PipelineState.FAILED`, waking all threads, and surfacing the error to the `async for` consumer.
- **Model OOM / GPU Faults**: Exceptions in `vlm.generate()` increment `inference_errors` and transition state cleanly.
- **Mid-Inference Cancellation**: `pipeline.stop()` called during active generation cleanly aborts and joins worker threads.

---

## 5. Backpressure & Stress Audit

Verified via `tests/test_stress.py`:
- **High Ingestion vs Slow Inference (30 FPS & 60 FPS)**: The scheduler drops stale frames once the temporal queue reaches capacity (`current_queue_depth <= max_temporal_frames`), maintaining constant bounded memory.
- **High-Rate Audio Ingestion**: `AudioScheduler` bounds memory to `max_buffered_s` (e.g. $\le 2.5\text{s}$).

## 6. Packaging & Dependency Audit

- **`pyproject.toml`**: Built with `maturin` backend (`_velo_native` extension module).
- **Core Dependencies**:
  - `torch` (CUDA-enabled)
  - `PyNvVideoCodec` (NVIDIA Video Codec SDK bindings)
  - `websockets`, `livekit-protocol`, `livekit-api`
- **Native Extension**: `_velo_native.cp313-win_amd64.pyd` dynamically links against `webrtc-rs` and `opus`.

## 8. Benchmark Integrity & Removal of Stale Claims

All benchmark claims in `README.md` and documentation now strictly reflect real hardware measurements:
- **Synthetic frame copying**: Explicitly classified as `Class 1 (Synthetic Infrastructure)` and excluded from decode claims.
- **Hardware NVDEC Decoding**: Verified at **3,486 FPS (480p)**, **1,695 FPS (720p)**, **628 FPS (1080p)**, **121 FPS (4K)** across 3-run statistical suites.
