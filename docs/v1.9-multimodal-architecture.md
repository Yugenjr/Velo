# Velo V1.9 Real Multimodal AI Pipeline Architecture

## 1. Executive Summary

This document specifies the technical architecture for **V1.9 Real Multimodal AI Pipeline** in Velo.
Building upon the native video (NVDEC) and native audio (Opus) transports, V1.9 integrates video ingestion, audio processing (VAD/ASR), temporal alignment (`TemporalFusion`), and multimodal inference into a unified, high-performance runtime.

## 2. Component Architecture & Data Flow

### 2.1 Media Ingestion Layer
- **Video Ingestion Worker (`VeloVideoIngest`)**:
  - Pulls GPU `Frame`s via blocking `stream.next()`.
  - Records frame timestamp $T_{\text{video}}$ and inserts into `TemporalFusion` (`fusion.add_video(frame, timestamp)`).
  - Submits frame to `AIScheduler` (`scheduler.submit(frame)`).
- **Audio Ingestion Worker (`VeloAudioIngest`)**:
  - Pulls `AudioChunk`s via blocking `stream.next_audio()`.
  - Submits raw chunks to `AudioScheduler` (`audio_scheduler.submit(chunk)`).

### 2.2 Audio Processing Worker (`VeloAudioProcess`)
- Pulls fixed-duration consolidated audio chunks (e.g., 500ms @ 48kHz stereo) via `audio_scheduler.acquire()`.
- Runs Voice Activity Detection (`VAD.analyze(chunk)`):
  - If silence, bypasses expensive ASR.
  - If speech detected, invokes `ASRAdapter.transcribe(chunk) -> Transcript`.
- Inserts `Transcript` into `TemporalFusion`:
  - `fusion.add_audio(transcript, timestamp=transcript.start_timestamp, duration=chunk.duration)`.

### 2.3 Multimodal Inference Worker (`VeloInference`)
- Paced by `AIScheduler.acquire()`, ensuring only high-value, novel, or candidate frames trigger AI inference.
- Retrieves temporally aligned context from `TemporalFusion`:
  - `context = fusion.context(timestamp=frame.timestamp, window=context_window_s)`.
  - Context contains matched GPU `Frame`s and overlapping `Transcript`s.
- Invokes model inference:
  - `model.generate(frames=[frame], prompt=prompt, context=context)` (or `model.generate_multimodal(...)`).
- Sends `MultimodalResponse` to `asyncio.Queue` for consumption by the async application layer.
- Releases frame in scheduler (`scheduler.release()`) and updates adaptive feedback loop with combined latency.

## 3. Timestamp Semantics & Temporal Context

1. **Common Time Domain**: Video and audio timestamps use the unified session monotonic time domain (seconds since stream start).
2. **Context Windowing**:
   - For target frame timestamp $T_F$ and window $W$:
     - Included video frames: $T_V \in [T_F - W, T_F + W]$.
     - Included transcripts: $[T_{\text{start}}, T_{\text{end}}] \cap [T_F - W, T_F + W] \neq \emptyset$.
3. **GPU Frame Residency**:
   - Frames stored in `VideoObservation` retain their underlying DLPack capsule and NVDEC context reference.
   - No conversion to CPU NumPy or PIL images occurs during context assembly.

## 4. Bounded Memory & Backpressure Model

| Component | Policy | Bounds |
| :--- | :--- | :--- |
| **Native Video Queue** | Drop oldest | 3 frames (~100ms @ 30fps) |
| **Native Audio Queue** | Drop oldest | 100 chunks (~2.0s @ 50fps) |
| **AIScheduler Ring Buffer** | Drop oldest | `max_buffered_frames` (default: 30 frames) |
| **AudioScheduler Buffer** | Drop oldest | `max_buffered_s` (default: 30.0s) |
| **TemporalFusion History** | Drop oldest | `max_history_s` (default: 30.0s) |
| **Async Result Queue** | Bounded | 100 responses |

---

## 5. Threading & Lifecycle State Machine

- **States**: `CREATED` -> `STARTING` -> `RUNNING` -> `STOPPING` -> `STOPPED` / `FAILED`.
- **Cascading Shutdown**:
  - Closing `Stream` unblocks ingestion threads.
  - Ingestion thread termination closes `AIScheduler` and `AudioScheduler`.
  - Inference thread unblocks on `SchedulerClosedError`, joins cleanly, and emits `StopIteration` to `asyncio.Queue`.
