# Velo V1.0.0 Release Notes

## Overview
Velo V1.0.0 is the first stable release of the native GPU WebRTC processing pipeline. This release introduces a verified, end-to-end integration for processing live WebRTC and LiveKit video streams natively into PyTorch CUDA tensors without CPU bottlenecks.

## Verified Capabilities
- **Zero-Copy Architecture**: Successfully routes H.264 NAL units from the network layer to the NVIDIA NVDEC hardware decoder and directly into GPU-resident DLPack `PyCapsule` instances.
- **Python Integration**: Clean, GIL-free concurrent integration via `PyO3`, ensuring the Python runtime does not block during frame arrival.
- **LiveKit Support**: Verified support for subscribing to LiveKit video tracks using local instances.
- **Direct PyTorch Interop**: Produces `torch.uint8` CUDA tensors mapped directly from GPU surface memory (zero-copy), ready for inference.

## Performance Result
End-to-End (E2E) testing against a local LiveKit instance yielded:
- **Connection setup latency**: 0.382 s
- **Resolution/Format**: 720x1280 (H.264 RGB), `torch.uint8` on `cuda:0`
- **Dropped frames**: 0
- **Decode errors**: 0
- **Stability**: Tested with continuous flow producing 127 consecutive frames matching test track output perfectly.

## Installation
The package is distributed as a compiled wheel for Windows x64.

**Prerequisites:**
You must provide a CUDA-enabled PyTorch installation and the NVIDIA `PyNvVideoCodec` SDK.

**Command:**
```bash
pip install velo
```
*See the [Installation Guide](installation.md) for full setup instructions.*

## Public API
The primary interfaces stabilized in V1.0.0 are:
- `velo.connect(sdp_offer)`: Negotiate raw WebRTC connections.
- `velo.connect_livekit(url, token)`: Subscribe to a LiveKit track natively.
- `velo.Stream`: Context manager for retrieving decoded frames.
- `velo.Frame`: GPU-resident wrapper exposing `.to_torch()` for tensor mapping.
- Top-level domain exceptions (`VeloError`, `HardwareError`, `MediaError`, `VeloConnectionError`, `StreamClosedError`, `DecodeError`).

*See the [API Reference](api.md) for full details.*

## Known Limitations
The following are **not** supported or verified in V1.0.0:
- **ABI3 Forward Compatibility**: The extension is built strictly for CPython 3.13 on Windows.
- **LiveKit Cloud**: Currently untested; only local instances verified.
- **CPU Fallback**: No software decoder fallback exists if CUDA/NVDEC is missing.
- **4K Streams**: 4K resolution configurations are unsupported and untested in this release.
